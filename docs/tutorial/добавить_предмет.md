# Как добавить новый предмет

Предметы — это то, что кладётся в инвентарь/хотбар. Хранятся в папке:

```
data/vanilla/item/*.json
```

Каждый файл = один предмет. Имя файла должно совпадать с `id` предмета.

---

## Минимальный предмет

`data/vanilla/item/my_item.json`:

```json
{
  "id": "my_item",
  "name": "Мой предмет",
  "maxStackSize": 64
}
```

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `id` | да | Уникальный идентификатор (латиницей, нижним подчёркиванием). Совпадает с именем файла. |
| `name` | нет | Отображаемое имя (можно на русском). По умолчанию = `id`. |
| `maxStackSize` | нет | Максимум предметов в одном слоте (по умолчанию 64). |

---

## Предмет, который ставит блок

Чтобы предмет ставился в мир как блок, добавь поле `placeBlock` — id блока:

`data/vanilla/item/pipe.json`:

```json
{
  "id": "pipe",
  "name": "Труба",
  "maxStackSize": 64,
  "placeBlock": "pipe"
}
```

Теперь при ПКМ этим предметом поставится блок `pipe`.

---

## Как предмет выглядит в инвентаре (текстура)

Иконка ищется автоматически:
1. `texture/item/{id}.png` — если есть отдельная иконка предмета;
2. иначе `texture/block/{id}.png` — текстура блока с тем же id;
3. иначе — розово-чёрная «missing» клетка.

Для руды `iron_ore` отдельная текстура не нужна — игра возьмёт `texture/block/iron_ore*.png`.

---

## Регистрация

Ничего регистрировать вручную не нужно. При запуске игра сама прочитает
все JSON из `data/vanilla/item/` (`DataLoader.loadItems`).

---

## Реальный пример (простой предмет)

`data/vanilla/item/circuit.json`:

```json
{
  "id": "circuit",
  "name": "Схема",
  "maxStackSize": 64
}
```
