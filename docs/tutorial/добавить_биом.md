# Как добавить новый биом

Биомы определяют, какой блок-пол и какие руды будут в регионе мира.
Хранятся в папке:

```
data/vanilla/biome/*.json
```

---

## Структура файла

`data/vanilla/biome/forest.json`:

```json
{
  "id": "forest",
  "minTemperature": 0.5,
  "maxTemperature": 1.0,
  "minHumidity": 0.0,
  "maxHumidity": 1.0,
  "surfaceBlock": "grass",
  "ores": {
    "iron_ore":   { "rarity": 0.75, "width": 0.035, "minCount": 1, "maxCount": 4 },
    "copper_ore": { "rarity": 0.75, "width": 0.030, "minCount": 2, "maxCount": 6 }
  }
}
```

---

## Поля

| Поле | Описание |
|------|----------|
| `id` | Уникальный идентификатор биома. |
| `minTemperature` / `maxTemperature` | Диапазон температуры (от 0.0 до 1.0), при котором выбирается биом. |
| `minHumidity` / `maxHumidity` | Диапазон влажности (от 0.0 до 1.0). |
| `surfaceBlock` | Блок-пол этого биома (id блока, например `grass`, `sand`, `stone`). |
| `ores` | Карта руд: ключ = id руды, значение = параметры жилы. |

При совпадении (температура И влажность в диапазоне) биом считается подходящим.
Если не подошёл ни один — берётся первый зарегистрированный (fallback).

> Совет: диапазоны биомов не должны пересекаться по температуре, иначе
> порядок загрузки файлов (по алфавиту) решит, какой биом победит.

---

## Про руды в биоме (жильная генерация)

Руды теперь генерируются ЖИЛАМИ (см. «генерация_мира.md»). Параметры:

| Параметр | Описание |
|----------|----------|
| `rarity` | Порог «редкости» (0.4 — часто, 0.8 — редко). FBM-маска должна быть больше этого значения. |
| `width` | Полуширина жилы вокруг ядра шума (0.025–0.035 — узкие жилы). |
| `minCount` / `maxCount` | Сколько предметов руды в одном блоке. Вблизи центра жилы — ближе к maxCount. |

Чем меньше `width` — тем тоньше жила. Чем больше `rarity` — тем реже руда.

---

## Пример: пустыня с редким золотом

`data/vanilla/biome/desert.json`:

```json
{
  "id": "desert",
  "minTemperature": 0.9,
  "maxTemperature": 1.0,
  "minHumidity": 0.0,
  "maxHumidity": 0.1,
  "surfaceBlock": "sand",
  "ores": {
    "gold_ore": { "rarity": 0.60, "width": 0.030, "minCount": 1, "maxCount": 3 }
  }
}
```

---

## Как добавить новую руду в биом

1. Убедись, что у руды есть блок и предмет (`data/vanilla/block/{id}.json`,
   `data/vanilla/item/{id}.json`) и модель/текстура.
2. Добавь запись в `ores` этого биома: `"my_ore": {"rarity": ..., "width": ..., "minCount": ..., "maxCount": ...}`.
3. Запусти игру — руда появится жилами в местах этого биома.

---

## Регистрация

Автоматически из всех JSON в `data/vanilla/biome/` при запуске (`DataLoader.loadBiomes`).
