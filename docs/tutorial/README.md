# Инструкции по добавлению контента

Здесь собраны пошаговые инструкции, как добавлять новые элементы игры.
Все данные лежат в папке `data/vanilla/`.

## Содержание

- [Как добавить предмет](добавить_предмет.md)
- [Как добавить блок](добавить_блок.md)
- [Как добавить биом](добавить_биом.md)
- [Как добавить модель и текстуру](добавить_модель_и_текстуру.md)
- [Как добавить blockstate (варианты текстур)](добавить_blockstate.md)
- [Устройство генерации мира](генерация_мира.md)

## Структура папок

```
data/vanilla/
  ├── block/       — свойства блоков (+ parent/ базовые)
  ├── blockstate/  — варианты текстур по состоянию
  ├── item/        — предметы
  ├── biome/       — биомы (пол + руды)
  ├── model/block/ — модели блоков (связь с текстурами)
  └── texture/     — PNG-картинки (block/, item/, gui/)
```
