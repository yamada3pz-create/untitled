# Генерация мира (устройство)

Как создаётся ландшафт, биомы и руды.

---

## Общая схема

```
Game launch
  └─ DataLoader.loadAll()   — блоки, предметы, биомы, модели из data/vanilla/
  └─ PlayingState(world, seed)
       ├─ new World(worldName)            — мир + регионы
       ├─ seed = world.loadSeed(seed)     — сид из level.dat (или переданный)
       ├─ WorldGenerator(seed)            — генератор
       │    └─ PerlinNoise.setSeed(seed)  — инициализация шума
       └─ генерация чанков вокруг игрока  — generator.generateChunk(chunk)
```

---

## Ключевые классы

| Класс | Роль |
|-------|------|
| `generation/PerlinNoise` | Детерминированный шум. `setSeed` даёт одинаковый мир для одного сида. |
| `generation/Biome` / `Biomes` | Конфиг биома + реестр по температуре/влажности. |
| `generation/WorldGenerator` | Заполняет чанк: пол биома + руды + валуны. |
| `world/World` / `Region` / `Chunk` | Хранение тайлов, регионы 16×16, сохранение в `saves/`. |

---

## Шум (PerlinNoise)

- `getTemperature(x, y)` — карта температуры (-1..1).
- `getHumidity(x, y)` — карта влажности.
- `getFractalNoise(x, y)` — многооктавный шум (для маски редкости).
- `getOreNoise(oreName, x, y)` — жильный шум *конкретной* руды (0..1).

Каждый сид задаёт уникальное смещение. Один и тот же номер сида →
абсолютно одинаковый мир.

---

## Биомы

По точке (wx, wy) считаются температура и влажность → нормализуются в 0..1 →
`Biomes.matchBiome(temp, hum)` возвращает биом. Все биомы грузятся из
`data/vanilla/biome/*.json`.

Пол биома = `surfaceBlock`. Руды — из `ores` этого биома.

---

## Руды: жильная генерация (НЕ хэш-полосой!)

Для каждой руды биома:

1. Имя руды нормализуется (`iron_ore` → `iron`).
2. `oreNoise = PerlinNoise.getOreNoise(ore, wx, wy)` — независимый шум.
3. `mask = fractal/2+0.5` — маска редкости.
4. Условие жилы:
   ```
   |oreNoise - 0.5| < width   И   mask > rarity
   ```
5. Количество руды в блоке растёт к центру жилы:
   ```
   factor = (width - |oreNoise-0.5|) / width
   amount = minCount + factor * (maxCount - minCount)
   ```

В итоге руды идут **жилами**, а жилы разных руд **не пересекаются**
(у каждой руды свои смещения шума).

Настройка: в биоме (`data/vanilla/biome/*.json`) — `width` (толщина жилы),
`rarity` (редкость маски), `minCount`/`maxCount`.

---

## Сид

- При создании мира сид задаётся в `CreateWorldState` (или случайно).
- Сохраняется в `saves/{world}/level.dat`.
- При повторном входе в мир берётся сохранённый сид — мир не меняется
  (`PlayingState` через `world.loadSeed`).

---

## Валуны (object-слой)

Помимо пола и руд, `WorldGenerator` очень редко ставит блоки-объекты
(`wall`) через периодическую хэш-функцию. Это не зависит от жильных руд.

---

## Слои тайла (Chunk)

У каждой клетки чанка несколько слоёв:
- `floorId` — пол биома (рисуется тёмным);
- `oreId` — руда (подсвечена);
- `objectId` — объект/блок (поверх всего);
- `objectState` — состояние объекта;
- `oreAmount` — сколько руды в блоке.
