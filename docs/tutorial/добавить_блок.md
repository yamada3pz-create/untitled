# Как добавить новый блок

Блоки — это «тайлы» мира (пол, руда, стена, машина и т.д.). Хранятся в папке:

```
data/vanilla/block/*.json
```

Каждый файл = один блок. Имя файла совпадает с `id`.

---

## Все поддерживаемые поля

| Поле | Тип | По умолч. | Описание |
|------|-----|-----------|----------|
| `parent` | string | — | Имя блока-родителя (наследование). См. ниже. |
| `id` | string | — | Уникальный идентификатор. Совпадает с именем файла. |
| `name` | string | id | Отображаемое имя (можно на русском). |
| `type` | string | "Block" | Тип расширения (пока не критично). |
| `layer` | string | "object" | Слой: `floor`, `object`, `overlay`, `none`. |
| `isSolid` | bool | true | Твёрдый ли (не проходишь сквозь). |
| `destroyTime` | float | 1.0 | Время разрушения (сек). |
| `drillTier` | int | 0 | Минимальный «тир» бура для добычи. |
| `infinite` | bool | false | Бесконечен ли (пол не расходуется). |
| `defaultAmount` | int | 0 | Количество по умолчанию (для руд). |
| `drops` | string | "" | Что выпадает при разрушении (id предмета). |
| `hasRotation` | bool | false | Имеет поворот (для машин/труб). |
| `hasBlockEntity` | bool | false | Есть ли блок-энтити (сундук, труба, машина). |
| `connectsToTags` | array | [] | Теги соединения (для труб). |
| `moveSpeed` | float | 1.0 | Множитель скорости движения по блоку. |

---

## Наследование через `parent`

Чтобы не повторять общие свойства, используют базовые блоки:

- `parent/base_floor.json` — пол: `layer: floor`, `isSolid: false`, `infinite: true`.
- `parent/base_ore.json` — руда: `layer: overlay`, `isSolid: false`, `drillTier: 1`, `defaultAmount: 20`.

Пример пола `data/vanilla/block/grass.json`:

```json
{
  "parent": "base_floor",
  "id": "grass"
}
```

Пример руды `data/vanilla/block/iron_ore.json`:

```json
{
  "parent": "base_ore",
  "id": "iron_ore",
  "name": "Железная руда",
  "drops": "iron_ore"
}
```

## Простой блок без родителя (стена)

`data/vanilla/block/wall.json`:

```json
{
  "id": "wall",
  "name": "Стена",
  "destroyTime": 1.5,
  "drops": "wall"
}
```

(по умолчанию `layer: object`, `isSolid: true` — твёрдая стена).

---

## Блок с блок-энтити (сундук)

`data/vanilla/block/chest.json`:

```json
{
  "type": "Block",
  "id": "chest",
  "name": "Сундук",
  "layer": "object",
  "isSolid": true,
  "hasBlockEntity": true,
  "infinite": false,
  "destroyTime": 0.8,
  "drops": "chest"
}
```

---

## Блок с поворотом и соединением (труба)

`data/vanilla/block/pipe.json`:

```json
{
  "type": "Block",
  "id": "pipe",
  "name": "Труба",
  "layer": "object",
  "isSolid": false,
  "hasRotation": true,
  "hasBlockEntity": true,
  "connectsToTags": ["pipe", "pump"],
  "infinite": false,
  "drops": "pipe"
}
```

---

## Что ещё нужно для блока

1. **Текстура** — `texture/block/{id}.png` (подробнее в «добавить_модель_и_текстуру.md»).
2. **Модель** — `model/block/{id}.json`, чтобы блок нашёл свою текстуру.
3. (Возможно) **Предмет** — если блок должен лежать в инвентаре (`data/vanilla/item/{id}.json`).
4. (Если есть `hasBlockEntity`) — Java-класс блок-энтити и регистрация в `BlockEntityType`.

---

## Регистрация

Регистрируется автоматически при запуске из всех JSON в `data/vanilla/block/`
(`DataLoader.loadBlocks`). Id присваивается автоматически.
